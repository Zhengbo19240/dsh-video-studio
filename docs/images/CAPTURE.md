# 截图作业单

README「截图」那一节的三个占位。这三张**由发布者亲自截**，不拿渲染图或示意图冒充——那一节自己写着这句话。

截完按下面的文件名放进本目录，README 里三行占位就能换成真实图片。

---

## 1. `workbench.png` — 工作台面板：时间线 + 预览 + 检查器

**用哪个工程**：`D:\DeepseekHarnessProject\视频dsh-video-table介绍\dsh-video-intro-v2`
这是本项目的真实成片工程：134.35 秒、11 个代码图层、55 个片段、BGM 3 段 + 音效 41 个、标注 4 条。

**摆什么状态**（这一帧要同时看得见三块）：
- 播放头停在 **69 秒左右**，预览区是工作台那一段（画面信息最满的一帧）
- 左侧栏：动效库 / 音效库 / 素材三块都露出来
- 下方时间线：能看到主轨、代码图层轨、音频轨、音效轨、标注轨，且标注轨上有四色方块
- 右侧检查器：属性面板展开

**为什么是这一帧**：一屏里同时出现「时间线 + 预览 + 检查器」，正是这一节要说明的东西；而且画面里有真实的工程名和片段数，读者一眼能看出不是示意图。

## 2. `agent-edit.png` — 对话里让 agent 改一个片段，面板同步变化

**摆什么状态**：左边/下方是对话说的一句话（例如「30.70 那格流程卡太小，放大一点」），工作台面板上对应的片段被选中、或该片段的缩略图已经变了。

**要点**：这一张要让人看出**因果**——说的话和面板的变化是同一个东西。所以两者必须同屏，且能对上位置。

**不要**用两次截图拼接；同屏才有说服力。

---

## 3. `motion-lib.png` — 动效库列表与一张卡的预览

**摆什么状态**：左侧动效库列表展开（能看到条目名与缩略图），右侧或下方是其中一张卡的预览画面。

**建议**：挑一张辨识度高的卡（例如卡片群翻飞转场、数字滚动），缩略图读得清，条目名完整。

## 通用要求

| 项 | 要求 |
|---|---|
| 格式 | PNG |
| 宽度 | ≥ 1600px，三张保持一致（推荐 1920 或当前屏幕 1:1） |
| 主题 | 三张用同一主题（深色或浅色，别混） |
| 裁切 | 不裁掉窗口边框以外的杂物；不要出现私人路径、API key、无关的聊天记录 |
| 文件名 | 严格用 `workbench.png` / `agent-edit.png` / `motion-lib.png` |
