# 视频生产工作流（工序、并发、统稿）

> 这份文档定义「谁来干、按什么顺序干、怎么保证不割裂」。
> 它要写进视频预设的提示词，所以**规则必须是可判定的**，不能写成建议。
> 最后更新：2026-11-06

---

## 一、为什么要有这份东西

实测出现过三类失败，全部来自「没有工序约定」：

1. **画面、音效、配乐同时做** → 音效对不上切点，配乐盖住口播，返工三遍。
2. **按时长切任务给多个 agent**（10 分钟片切成 5 段 2 分钟）→ 一个叙事单元被劈成两半，接缝处必然断。
3. **各模块各写各的** → 同一支片子出现两套配色、两种字重、两种转场语言。

结论：**工序必须串行，并发只能按模块，收尾必须有人统稿。**

---

## 二、工序：四步，严格串行

```
① 画面（含转场、定镜头时长）
      ↓ 画面锁定后才许动声音
② 音效（贴画面切点，含转场音）
      ↓ 音效铺完，才知道哪里要留白
③ 配乐（避让音效与口播）
      ↓ 全部就位
④ 统稿（连贯性检查 + 接缝处理 + 微调）
```

### 为什么不能并行

| 反对的并行 | 后果 |
|---|---|
| 画面 + 音效同时 | 画面一改，音效落点全废 |
| 音效 + 配乐同时 | 配乐占住频谱，音效被淹；或反过来音效刺耳 |
| 任一 + 统稿同时 | 统稿改的东西下一秒被覆盖 |

### 判定规则（写进预设）

- 画面未锁定（时间线主干片段未定稿）时，**禁止**调用 `video_sound_insert`、禁止配乐。
- 音效未铺完（该有声的画面对应段落无音效层）时，**禁止**配乐。
- 统稿开始的前提是**所有模块都已交付**；统稿期间**禁止**其它 agent 写同一工程。

---

## 三、并发：按模块切，不按时长切

### 模块的定义

**模块 = 一个叙事单元**，不是一段时长。判据：

- 一个模块只讲一件事（一个观点、一段流程、一个场景）
- 模块内部因果闭合：进来有铺垫，出去有落点
- 模块边界是**语义断点**，不是等分点

### 切分规则

```
总时长的均分点不是模块边界
先按脚本站位切模块（脚本里的 shot 分组）
再检查每块 40 秒 ~ 3 分钟（太短合，太长拆）
最后确认每个模块边界处在语法上可以停
```

### 每个模块交付物（缺一不可）

```
- 该模块的时间线片段（自己区间内，不越界）
- 该模块用到的图层/素材，命名带模块前缀（m03-xxx）
- 自检报告：本模块的 jump 数、最长静帧、起止帧状态
```

### 风格一致性靠什么保证

不靠「大家注意点」，靠**一份共享的风格契约**：

- `style.json`（tone / palette / font / density / pace）是所有模块的唯一权威
- 模块里的颜色、字号、间距必须从契约取值；**不允许自造**
- 转场语言统一（例如全片只用 3 种转场），转场选择也从契约来
- 交稿时附一句「本模块用到的契约字段」；用了契约外的值要显式声明理由

---

## 四、统稿：一个人，只做三件事

统稿 agent 不改内容，只处理**接缝**：

| 动作 | 具体做什么 | 不做什么 |
|---|---|---|
| 接缝检测 | 对每个模块边界前后各 1 秒做连续性检查，列出 jump / 静帧 / 速度突变 | 不重写模块内容 |
| 转场缝合 | 在边界插入或调整转场，让两个模块的出入点咬合 | 不改模块内部节奏 |
| 全局微调 | 统一速度曲线、统一淡入淡出、对齐音乐重音 | 不新增镜头 |

统稿结束的判据：

```
① 每个接缝的 jump 数 = 0 或低于阈值
② 全片静帧占比 < 5%
③ 全片速度曲线无二阶突变（velocityJerkP95 在阈值内）
④ 色彩/字体/间距抽查 5 帧，全部来自契约
```

## 五、配额与并发（与本机实现对齐）

```
面板启用额度 = 2         面板同时挂载的工程数（显存/内存约束）
agent 并发    = 不限      子 agent 改的是同一份工作台，不重复占资源
```

- 额度只统计 `origin:'panel'` 的工程；agent 打开的工程不占额度
- 多个 agent 写同一工程靠**写租约**串行化（`lease`），不靠额度
- 同一时刻同一文件只允许一个 agent 写；冲突时后到的等待或失败重试

---

## 六、要写进预设的判定句

```
开工前必须完成：问询（10 项）→ 写脚本 → 用户确认 → 样片与关键帧 → 用户定风格
工序必须串行：画面 → 音效 → 配乐 → 统稿；上一步未锁定，不许开始下一步
并发只能按模块：一个模块一个人；禁止按时长均分
模块必须自洽：每模块交付时间线片段 + 自检报告 + 用到的契约字段
收尾必须统稿：接缝检测 → 转场缝合 → 全局微调；统稿期间禁止其它写入
```
